# 6. UI 前端开发

## 6.1 原型对应关系

参考 [原型图](../原型图设计.png)。以 StarAdmin 品牌、蓝白色企业后台和左侧导航为基础；原型首页为设计依据，其他页面为本次补充设计。

## 6.2 视觉与布局

| 项目 | 建议规范 |
| --- | --- |
| 主色 | #1677FF，成功 #16B777，警示 #FAAD14，危险 #F04455 |
| 背景/文字 | 页面 #F4F7FC，卡片 #FFFFFF；正文 #253858，辅助 #66758F |
| 导航 | 展开 232px、收起 64px，顶栏 60px；内容区允许独立滚动 |
| 间距/圆角 | 8px 基准，卡片间距 16px，内容边距 24px，圆角 8–12px |
| 字体 | 系统中文无衬线；正文 14px、卡片标题 16px、核心数字 28–32px |
| 表格/表单 | 默认行高 44–48px，表单标签 96px，操作列固定右侧 |
| 响应式 | >=1440 四统计卡并排；1024–1439 两列；<1024 导航抽屉、内容单列 |

蓝色装饰横幅可用本地静态插画或 CSS，不能影响文字对比度。原型背景图不作为整页图片使用，所有按钮、表格和图表真实可交互。键盘焦点可见；输入框有 label；颜色之外提供状态文字。

## 6.3 导航与路由

| 路由 | 页面 |
| --- | --- |
| /login | 租户编码、账号、密码、登录；必要时验证码 |
| /dashboard | 原型首页 |
| /system/users、/system/roles、/system/menus | 用户、角色、菜单 |
| /system/depts、/system/posts | 部门、岗位 |
| /system/dicts、/system/configs | P1 数据字典、参数 |
| /business/projects | P1 项目示例 |
| /audit/operations、/audit/logins | 操作/登录日志 |
| /files、/attachments | P1 文件列表、按业务查询附件 |
| /monitor/overview、/monitor/sessions | P1 监控、在线会话 |
| /profile、/403、/404 | 个人中心及异常页 |

原型中的“部门应用”在 P2 定义为应用目录，需求未明确前隐藏。数据管理先承载字典/参数，不提供任意 SQL 执行入口。文件管理负责存储资源，附件管理负责业务关联，两者共用底层文件数据。

菜单由 `/auth/menus` 提供，componentKey 只能匹配前端预注册组件表；禁止后端传任意路径后动态执行导入。全局搜索只搜索已授权菜单。首版通知中心无数据源时隐藏图标，不显示误导性未读数。

## 6.4 首页组件

- 欢迎横幅：显示当前用户昵称；无昵称回退用户名；能力标签与实际启用模块一致。
- 统计卡：加载用骨架屏；无权限显示“暂无查看权限”；缺数据用 `—`，不得填随机值。
- 访问趋势：7/30/90 天切换，时间轴显示本地日期；后端补齐缺失日期，tooltip 展示日期和访问次数。
- 业务分布：显示真实 count，百分比前端计算，四舍五入允许说明；总计为 0 时显示空状态，未分类归“其他”。
- 快捷操作：新增用户/角色/菜单、上传文件、日志、配置，分别绑定对应权限。无可用操作时隐藏整个区块。
- 最近操作：ID、操作人、类型、摘要、时间、IP；按时间倒序；默认分页 5 条，可跳转日志页。IP 仅授权角色可见。
- 最新动态：仅展示后端已脱敏的可见事件；原型“329分钟前”等统一为“5小时前”，悬停展示绝对时间。
- 运行时间无周同比箭头；安全事件红色表示需关注，不能沿用原型中的绿色上升提示。

## 6.5 管理页面交互

| 页面 | 列表/筛选 | 表单与关键操作 |
| --- | --- | --- |
| 用户 | 部门树 + 账号/昵称/手机号/状态；账号、姓名、部门、岗位、状态、创建时间 | 新增/编辑抽屉；角色授权独立；重置密码/删除确认；编辑自己受限制 |
| 角色 | 名称/编码/状态；名称、编码、数据范围、人数 | 基础表单、菜单授权树、数据范围配置分别提交；显示版本冲突 |
| 菜单 | 树表；名称、类型、路由、权限码、排序、状态 | 目录/菜单/按钮切换；父级不能为按钮；组件下拉白名单 |
| 部门 | 树表；名称、排序、状态 | 选择父级时排除自己及子孙；有子部门/用户时不可直接删除 |
| 岗位 | 编码/名称/状态筛选 | 编码唯一，删除引用检查 |
| 字典/参数 | 类型、名称、状态 | 字典项独立维护；敏感参数不回显，部署密钥不进页面 |
| 日志 | 时间、操作者、结果、模块、类型 | 只读详情脱敏；默认近 7 天，最大同步查询 90 天 |
| 文件 | 文件名、类型、上传者、时间 | 上传进度/取消/失败重试；隔离中不可下载；已关联不可直接删除 |
| 在线会话 | 用户、登录时间、最近活跃、IP | 强制下线需要确认；不可查看 token |

角色授权树区分“显式授予”与“父节点导航补齐”。取消父节点不自动删除所有子权限，批量勾选有明确提示；后端只接收显式 menuIds。角色数据范围表单：ALL、DEPT_AND_CHILD、DEPT、CUSTOM、SELF；CUSTOM 必选合法部门，空集合表示拒绝而非全量。

## 6.6 组件和状态管理

复用 SearchForm、DataTable、FormDrawer、DeptTreeSelect、RolePermissionTree、PermissionButton、UploadPanel、StatusTag。表格分页筛选写入 URL；搜索后回到第 1 页，重置清空筛选。详情跳转后可返回原列表位置。

Pinia 拆分 auth、permission、app；auth 只保存内存 accessToken。刷新页面先尝试刷新会话，再获取 me 和 menus，最后注册路由。退出清空 token、用户、菜单、已注册路由和用户相关缓存。权限刷新后当前路由不可访问时跳转 403 或可访问首页。

请求层统一处理 traceId 和错误；401 单次刷新并重试一次，刷新失败清理登录态；403 不触发刷新；409 提示重新获取版本；上传失败保留重试入口。表单提交防连点，后端仍负责幂等。

## 6.7 页面验收

按原型在 1536×1024 检查导航、横幅、四卡、图表、操作表布局；同时检查 1440、1280、768 宽度。验证加载、空数据、接口失败、无权限、超长中文名、角色多选和密码改密流程。生产构建禁用 mock，未实现菜单不注册。
